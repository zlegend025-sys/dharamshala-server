# Dharamshala SMP

Official website source for **https://server.harshpreet.live** — the Dharamshala Minecraft SMP community.

This repository contains the landing page for the Dharamshala SMP server, providing players with information, access links, and community resources.

---

## 🌐 Live Website

https://server.harshpreet.live

---

## 🎮 About the Server

Dharamshala SMP is a community-driven **Minecraft Survival Multiplayer server** focused on a fair and friendly survival experience.

**Key Features**

* Survival SMP gameplay
* Whitelist-based access
* Active community
* Hosted in India 🇮🇳
* 24/7 uptime
* Discord community

---

## 🚀 Running Locally

If you want to run or edit the website locally:

1. Clone the repository

```
git clone https://github.com/yourusername/dharamshala-smp.git
```

2. Open the project folder

3. Open `index.html` in your browser

No build tools or dependencies are required.
